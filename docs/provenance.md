# References and provenance

Opsflow's application source was implemented specifically for this portfolio. The reference projects below informed the documentation approach; they are not upstream codebases or templates for this implementation.

The following public projects were inspected as references:

- [mhr202/leadsignal](https://github.com/mhr202/leadsignal): useful problem framing, architecture notes, offline demo fixtures, and test organization. Its source was inspected but not copied, and its reported test results were not independently reproduced in this review.
- [umer4447/slack-building-project-backend](https://github.com/umer4447/slack-building-project-backend): reviewed as an example of a small authentication backend. It was not used as a code template.

Reference checkouts were kept outside this repository. No assets, fixtures, algorithms, or source modules were imported from them. Dependencies listed in package.json retain their upstream licenses.

Commit timestamps are repository metadata; use the dated verification record for evidence of when checks were executed.
